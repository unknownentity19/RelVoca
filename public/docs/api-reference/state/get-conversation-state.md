# Get conversation state

> This endpoint still works but is no longer documented. The RelVoca REST API at /v1/stable is where current integrations should start.

<Note>
  **This endpoint still works, but it is no longer documented.**

  `GET /state/user/{userID}` is not deprecated and continues to function. It has
  no equivalent on the [RelVoca REST API](/docs/api-reference/api-overview) yet, so this
  page is kept reachable for anyone already calling it. New integrations should start
  from the REST API.
</Note>
