# Twilio tool

> Send SMS messages from your agent using your Twilio account. 

<img src="https://mintcdn.com/voiceflow-009a8802/s3P1FU2SwfLb9qjL/images/tools/integrations/Twilliocover-1.png?fit=max&auto=format&n=s3P1FU2SwfLb9qjL&q=85&s=d3f30a7132c1732139fc23d9bed552db" alt="Twilio tool cover" width="1920" height="1080" data-path="images/tools/integrations/Twilliocover-1.png" />

The Twilio tool lets your agent send text messages during a conversation. Use it to send confirmation codes, appointment reminders, order updates, or follow-up information to your users.

## Using the Twilio tool

Add the Twilio tool to your agent from **Tools** → **Add tool** → **Twilio**. You can also add tools directly from inside a [Playbook](/docs/documentation/build/steps/playbook) or [Integration step](/docs/documentation/build/steps/integration). Once added, you can call the Twilio tool from inside a [Playbook](/docs/documentation/build/playbooks) or [Workflow](/docs/documentation/build/workflows).

### Actions

| Action       | Description                                      |
| ------------ | ------------------------------------------------ |
| **Send SMS** | Send a text message to a specified phone number. |
